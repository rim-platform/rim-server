# Cleanup before going public (plan, 2026-10-10)

_Approved by Jakub on 2026-10-10 from three read-only reviews of rim-server. The rule: vanilla
RIM is a decentralized chat platform plus the programmable layer (commands, keybinds, macros,
pipelines, plugins, the AI command surface). Verticals are plugins. Nothing here changes what a
vanilla server does; it removes what nothing uses and what does not belong in a public repo._

## Rules for every PR

Same as `release-prep-2026-10-10.md`: a worktree off master, `CARGO_INCREMENTAL=0
CARGO_PROFILE_DEV_DEBUG=0`, every gate, plain imperative commits without trailers, the
coordinating session reviews and merges. Removals are deletions, not `#[allow(dead_code)]` or
commented-out code. A removal that changes the GraphQL schema exports the SDL for rim-ui. No
behaviour change for a vanilla server: a single server with today's configuration starts and
serves the same, minus the dropped module.
